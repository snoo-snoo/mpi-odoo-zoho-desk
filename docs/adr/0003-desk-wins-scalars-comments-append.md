# Desk wins Ticket fields; Comments append

When both sides write the same Ticket field in the same window, the Desk value is kept. Comments are append-only on both sides and are never last-write-wins. Last-write-wins across Zoho and Odoo clocks, Odoo-wins, per-field Connection winners, and a review inbox were rejected for v1: support already lives in Desk; Comments are events, not fields.
